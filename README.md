# Paint - Actividad 1

## Contenido

Este repositorio cuenta con el juego **Paint** descargado de `freegames` mediante un ambiente virtual de Python.

## Cambios

Se realizaron 3 cambios a través de 3 commits distintos**:

1. Agregar un color
2. Agregar la función círculo
3. Agregar la función rectángulo
4. Agregar la función triángulo

> **Nota:** Los primeros dos cambios se realizaron en el repositorio original; los últimos dos se realizaron en un *fork* y se unificaron al principal mediante un *pull request*.

El `README` se agregó en el repositorio original y se utilizó **fork sync** para agregarlo al *fork*.
